# Sample Space
## Definition
A well-defined collection of distinct unordered elements.
## Interpretation 

## Notation
The *elements* of a set are usually denoted by lower case letters, and the collection represented by curly brackets, for example:
$S = \{s_0, s_1, s_2, s_3\}$.
