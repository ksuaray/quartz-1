# Set Algebra
## Definition

Let $A$ and $B$ be two events in a sample space $\Omega$.
- Union: $A \cup B$ is the set of all elements in $\Omega$ that are in $A$ **or** in $B$.
- Intersection: $A \cap B$ is the set of all elements in $\Omega$ that are in $A$ **and** in $B$.
- [[Complement Probability|Complement]]: $A^c$ is the set of all elements in $\Omega$ that are **not** in $A$.
